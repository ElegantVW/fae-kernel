# House tongue — mana, crystals, casting

Whimsy in the *midst* of work. Not extra boot lines. All-ages.

| Mundane | House |
|---|---|
| byte (B) | thimble of **mana** |
| KiB | cup of mana |
| MiB | bowl of mana |
| GiB | well of mana |
| RAM / heap | the well |
| package / crate | **crystal** |
| `cargo` fetch | gathering crystals |
| load / boot | **cast** |
| `make` | bellows |
| panic | the spark went out |
| rebuild | recast |
| `distclean` | the forest forgets; the seed does not |

Use these in comments, `make help`, panics, and strings-on-the-ROM — not as a second serial protocol.
